# Парсер
Запуск из main.py позволяет скачивать все обнаруженные проекты из Engee Gitlab, в которых находятся файлы формата `.engee`. 

Работает поэтапно:
- парсинг ссылок
- установка файлов
- описание скачанных моделей в `.md` формате

Все установленные файлы (при запуске из `main.py`) сохраняются в папке `runs/`. Внутри создаются папки для каждого запущенного рана (с названием в формате `datetime-time` на момент запуска).

Без ключа парсинг и скачивание моделей работают в штатном режиме, шаг конвертации будет пропущен.

Чтобы запустить парсер **с опцией** описания моделей, необходимо выполнить команду: `python main.py -d`.
Для запуска **без опции** описания моделей: `python main.py --no-d`.

## Parser
Парсер собирает ссылки на проекты и файлы из проектов в тех репозиториях, где есть файлы `.engee`. Полученные файлы возвращает из функции main.
Сохраняет 2 файла: ссылки на проекты (caught_projects.txt) и ссылки на файлы (caught_models.txt). 

## Downloader
Скачивает файлы из гитлаба по переданным ссылкам, сохраняя их в папке `models/`.
> Из-за обилия моделей с одинаковым именем - сохраняется только один экземпляр.
> (Пользователи Engee проходят курсы, сохраняя файлы одинаковым именем. На 25.04.2026 из 5860 схваченных ссылок 
> установлено только 1190 файлов. Это больше отсеивание дубликаторв для датасета, потому что больша часть файлов - 
> однотипная, повторение друг друга)

## Converter
> Для работы конвертера моделей в Markdown нужен API-ключ от [OpenRouter](https://openrouter.ai/keys).
> В `.env` необходимо сохранить полученный API (пример в `.env.example`)

Конвертирует скачанные `.engee` модели в Markdown через OpenRouter AI.
Сохраняет результаты в папке `mds/`.
